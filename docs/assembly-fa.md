# راهنمای مونتاژ: دستگاه حضور و غیاب RFID

این راهنما شما را از قطعات جدا تا یک دستگاه آماده می‌برد: یک Wemos D1 mini با کارت‌خوان RC522، یک LED سبز و یک LED قرمز و یک بازر. همه با یک کابل USB تغذیه می‌شوند. زمان لازم حدود ۱ تا ۲ ساعت است.

**فهرست:** [۱. قطعات](#۱-قطعات) · [۲. ابزار](#۲-ابزار) · [۳. مدار](#۳-مدار) · [۴. اول Firmware را آپلود کنید](#۴-اول-firmware-را-آپلود-کنید) · [۵. سیم‌کشی](#۵-سیم‌کشی) · [۶. بررسی پیش از اتصال برق](#۶-بررسی-پیش-از-اتصال-برق) · [۷. اولین روشن کردن](#۷-اولین-روشن-کردن) · [۸. راه‌اندازی و ثبت کارت](#۸-راه‌اندازی-و-ثبت-کارت) · [۹. جعبه](#۹-جعبه) · [۱۰. رفع اشکال](#۱۰-رفع-اشکال) · [۱۱. اطلاعات مرجع](#۱۱-اطلاعات-مرجع)

## ۳. مدار

</div>

```
                 USB 5 V
                    │
             ┌──────┴───────────────┐
             │     Wemos D1 mini    │
             │                      │
   RC522 ────┤ 3V3            5V ───┼──── buzzer +  (option B: driver, see 5.4)
   (3.3 V)   │ G (GND)              │
             │ D8 ── SDA/SS         │
             │ D5 ── SCK            │
             │ D7 ── MOSI           │
             │ D6 ── MISO           │
             │ D0 ── RST            │
             │                      │
             │ D1 ── 220 Ω ── LED green ── GND
             │ D2 ── 220 Ω ── LED red   ── GND
             │ D3 ── buzzer input (silent when HIGH)
             └──────────────────────┘
```

<div dir="rtl">

| از | به | کاربرد |
|---|---|---|
| RC522 **SDA** | Wemos **D8** | انتخاب تراشهٔ SPI |
| RC522 **SCK** | Wemos **D5** | کلاک SPI |
| RC522 **MOSI** | Wemos **D7** | داده به سمت کارت‌خوان |
| RC522 **MISO** | Wemos **D6** | داده به سمت Wemos |
| RC522 **IRQ** | — | وصل نکنید |
| RC522 **GND** | Wemos **G** | زمین |
| RC522 **RST** | Wemos **D0** | ریست کارت‌خوان |
| RC522 **3.3V** | Wemos **3V3** | ⚠ **هرگز به 5V وصل نکنید** |
| LED سبز (از طریق ۲۲۰ اهم) | Wemos **D1** | پایهٔ بلند (+) به سمت مقاومت |
| LED قرمز (از طریق ۲۲۰ اهم) | Wemos **D2** | پایهٔ بلند (+) به سمت مقاومت |
| ورودی بازر | Wemos **D3** | [بخش ۵-۴](#۵-۴-بازر) را ببینید |
| همهٔ GNDها | Wemos **G** | زمین مشترک |

## ۴. اول Firmware را آپلود کنید

آپلود پیش از سیم‌کشی ثابت می‌کند که Wemos و کابل سالم‌اند، و لاگ سریال می‌دهد که با آن هر مرحله را بررسی کنید.

**۱. نصب ابزارها**

</div>

```bash
pip install platformio          # یا افزونهٔ PlatformIO در VS Code
git clone https://github.com/Aryalleh/Attendance-device.git
cd Attendance-device/firmware
```

<div dir="rtl">

- **ویندوز:** اگر با وصل کردن Wemos پورت COM ظاهر نشد، درایور CH340 را نصب کنید.
- **لینوکس:** خودتان را به گروه `dialout` اضافه کنید، سپس یک بار خارج و دوباره وارد شوید: `sudo usermod -aG dialout $USER`

**۲. تنظیم نوع بازر.** فایل `firmware/src/config.h` را باز کنید و این مقدار را بگذارید:

</div>

```cpp
#define BUZZER_ACTIVE_LOW  true    // گزینهٔ الف (Low-level trigger) و گزینهٔ ب (مدار ترانزیستوری)
```

<div dir="rtl">

اگر LEDها را مطابق این راهنما وصل می‌کنید، `LED_ACTIVE_LOW false` را تغییر ندهید.

**۳. کامپایل و آپلود**

</div>

```bash
pio run -t upload
pio device monitor              # 115200 baud، خروج با Ctrl+C
```

<div dir="rtl">

وقتی هنوز چیزی وصل نیست، لاگ باید این را نشان دهد:

</div>

```
[boot] RFID access controller 1.0.0
[boot] reader NOT FOUND (version 0x00), mode standalone, 0 cards
[rfid] 0x00: RC522 unpowered (3.3V/GND), held in reset (RST->D0), or MISO shorted to GND
```

<div dir="rtl">

پیدا نشدن کارت‌خوان در این مرحله طبیعی است. پیش از سیم‌کشی **کابل USB را جدا کنید**.

## ۵. سیم‌کشی

همهٔ سیم‌کشی را **با کابل USB جدا** انجام دهید.

### ۵-۱. پین‌هدرها

اگر پین‌هدرها لحیم نشده‌اند، آن‌ها را روی Wemos و RC522 لحیم کنید. روی RC522 پین‌هدر را در سمتی بگذارید که **از سیم‌پیچ آنتن دور** است.

### ۵-۲. کارت‌خوان RC522

هفت سیم را مطابق [جدول بالا](#۳-مدار) وصل کنید. سیم **3.3V** را دوباره بررسی کنید: روی Wemos باید به پایه‌ای با برچسب **3V3** برود، نه **5V**. ولتاژ ۵ ولت می‌تواند RC522 را بسوزاند.

سیم‌ها را کوتاه نگه دارید (کمتر از حدود ۱۵ سانتی‌متر). سیم‌های بلند SPI باعث خطای خواندن می‌شوند.

### ۵-۳. LEDها

برای هر LED:

</div>

```
Wemos D1 ──[220 Ω]──►|── GND        (green / سبز)
Wemos D2 ──[220 Ω]──►|── GND        (red / قرمز)
                  long  short
                  leg   leg (flat side of the LED body)
```

<div dir="rtl">

**پایهٔ بلند** (آند، +) به سمت مقاومت و پایهٔ Wemos می‌رود. **پایهٔ کوتاه** (کاتد، −، کنار لبهٔ صاف بدنهٔ LED) به GND وصل می‌شود.

### ۵-۴. بازر

**گزینهٔ الف: ماژول Low-level trigger (سه‌پایه)**

| پایهٔ ماژول | Wemos |
|---|---|
| VCC | 5V |
| GND | G |
| I/O (یا IN) | D3 |

**گزینهٔ ب: بازر فعال ۵ ولت با مدار دو ترانزیستوری**

</div>

```
                         +5V                    +5V
                          │                      │
                       [10 kΩ]                 (+) buzzer
                          │                      │
 D3 ──[47 kΩ]──B  Q1      ├──────────B  Q2      (−)
                 BC547    │            BC337     │
                C ────────┘           C ─────────┘
                E ── GND              E ── GND
```

<div dir="rtl">

طرز کار:

- **D3 در سطح HIGH** (هنگام روشن شدن و در حالت عادی): Q1 روشن می‌شود و بیس Q2 را LOW می‌کند، پس Q2 خاموش و بازر ساکت است.
- **D3 در سطح LOW**: Q1 خاموش می‌شود، مقاومت ۱۰ کیلواهم Q2 را روشن می‌کند و بازر صدا می‌دهد.

به همین دلیل تنظیم Firmware باید `BUZZER_ACTIVE_LOW true` باشد.

**پایه‌های ترانزیستور (BC547 و BC337، بستهٔ TO-92):** ترانزیستور را طوری بگیرید که **سطح صاف آن رو به شما** و پایه‌ها پایین باشند. از چپ به راست پایه‌ها **C – B – E** هستند (کلکتور، بیس، امیتر). بعضی سازنده‌ها متفاوت‌اند، پس با دیتاشیت یا حالت دیود/hFE مولتی‌متر بررسی کنید.

پایهٔ **+** بازر (پایهٔ بلندتر یا سمت علامت «+») به 5V وصل می‌شود.

## ۶. بررسی پیش از اتصال برق

در حالی که USB هنوز جداست، مولتی‌متر را روی حالت تست اتصال (بوق) بگذارید:

| اندازه‌گیری بین | نتیجهٔ درست |
|---|---|
| 5V و G روی Wemos | **بوق نزند** (اتصال کوتاه نیست) |
| 3V3 و G روی Wemos | **بوق نزند** |
| 3.3V روی RC522 و 3V3 روی Wemos | بوق بزند |
| GND روی RC522 و G روی Wemos | بوق بزند |
| هر پایهٔ سیگنال RC522 و پایهٔ متناظر Wemos (SDA–D8، SCK–D5، MOSI–D7، MISO–D6، RST–D0) | بوق بزند |
| 3.3V روی RC522 و 5V روی Wemos | **بوق نزند** |

پیش از وصل کردن برق، هر مورد غیرمنتظره را درست کنید.

## ۷. اولین روشن کردن

USB را وصل کنید و مانیتور سریال را باز کنید (`pio device monitor`). باید این را ببینید:

</div>

```
[boot] RFID access controller 1.0.0
[boot] reader OK (version 0x92), mode standalone, 0 cards
[wifi] setup AP "RFID-Setup-xxxxxx" pass "rfid12345" at 192.168.4.1
```

<div dir="rtl">

- عبارت `version 0x92` (یا `0x91`، `0x88`، `0xB2`) یعنی RC522 درست وصل شده است.
- LEDهای سبز و قرمز و بازر یک الگوی کوتاه شروع پخش می‌کنند.
- **بازر نباید هنگام روشن شدن بُرد مدام صدا بدهد.** اگر صدا داد، [رفع اشکال](#۱۰-رفع-اشکال) را ببینید.
- یک کارت روی کارت‌خوان بگیرید. لاگ `[scan] 04:A3:1B:2C` را نشان می‌دهد و LED قرمز با بوق یعنی «کارت ناشناس». این درست است، چون هنوز کارتی ثبت نشده.

## ۸. راه‌اندازی و ثبت کارت

1. با گوشی یا کامپیوتر به Wi-Fi با نام **`RFID-Setup-xxxxxx`** و رمز **`rfid12345`** وصل شوید.
2. **http://192.168.4.1** را باز کنید و با **admin / admin** وارد شوید.
3. در **تنظیمات**:
   - **رمز مدیر را عوض کنید.**
   - حالت را انتخاب کنید: **مستقل** (کارت‌ها روی خود دستگاه) یا **سرور** ([README](../README.fa.md#حالت-سرور) را ببینید).
   - نام و رمز Wi-Fi خود را وارد کنید، یا «بدون روتر — دستگاه وای‌فای خودش را می‌سازد» را تیک بزنید تا دستگاه Wi-Fi خودش را نگه دارد.
   - **ذخیره و راه‌اندازی مجدد** را بزنید.
4. **ثبت کارت (حالت مستقل):** در زبانهٔ **کارت‌ها** نام فرد را بنویسید، دکمهٔ «ثبت با کارت‌زدن» را بزنید و کارت او را روی کارت‌خوان بگیرید. در زمان انتظار، LEDها به‌تناوب سبز و قرمز چشمک می‌زنند.
5. آزمایش: یک کارت ثبت‌شده را روی کارت‌خوان بگیرید. باید چراغ سبز و بوق کوتاه بگیرید و زبانهٔ **گزارش** ورود را نشان دهد.

## ۹. جعبه

- **پلاستیکی، نه فلزی.** فلز نزدیک آنتن RC522 جلوی خواندن کارت را می‌گیرد. آنتن را مستقیماً پشت دیوارهٔ جلویی نصب کنید و ضخامت دیواره حداکثر حدود ۳ میلی‌متر باشد. فاصلهٔ خواندن ۲ تا ۴ سانتی‌متر است.
- Wemos و سیم‌هایش را **حداقل ۱ تا ۲ سانتی‌متر دور از آنتن** یا پشت آن قرار دهید.
- برای LEDها سوراخ ۵ میلی‌متری و روی بازر یک سوراخ یا شیار بگذارید تا صدا شنیده شود.
- **پورت USB بُرد Wemos را در دسترس** بگذارید، برای تغذیه و به‌روزرسانی‌های بعدی Firmware.
- بُردها را با پیچ، اسپیسر یا چسب حرارتی ثابت کنید تا هیچ قطعه‌ای به قطعهٔ دیگر اتصال کوتاه نکند.
- جای زدن کارت را روی جعبه با یک علامت کارت مشخص کنید.

## ۱۰. رفع اشکال

| مشکل | علت احتمالی | راه‌حل |
|---|---|---|
| پورت COM یا `/dev/ttyUSB0` ظاهر نمی‌شود | کابل فقط شارژ، نبود درایور، یا دسترسی در لینوکس | کابل دیتادار؛ نصب درایور CH340؛ `sudo usermod -aG dialout $USER` |
| خطای آپلود «Timed out waiting for packet header» | کابل خراب یا پورت در حال استفاده | مانیتورهای سریال دیگر را ببندید؛ `--upload-speed 115200`؛ کابل دیگر |
| لاگ: `reader NOT FOUND (version 0x00)` | RC522 برق ندارد، RST پایین نگه داشته شده، یا MISO به GND اتصال کوتاه دارد | سیم‌های 3.3V و GND و اتصال RST به D0 را بررسی کنید |
| لاگ: `reader NOT FOUND (version 0xFF)` | MISO وصل نیست یا SDA سیم‌کشی نشده | اتصال MISO به D6 و SDA به D8 را بررسی کنید |
| بُرد بالا نمی‌آید یا لاگ بعد از چند کاراکتر نامفهوم متوقف می‌شود | چیزی **D3 را LOW** یا **D8 را HIGH** می‌کند | بازر را جدا کنید و دوباره امتحان کنید؛ از گزینهٔ الف یا ب استفاده کنید، نه بازر ساده روی D3 |
| بازر هنگام روشن شدن مدام بوق می‌زند | تنظیم قطبیت اشتباه است | در `config.h` مقدار `BUZZER_ACTIVE_LOW true` بگذارید و دوباره آپلود کنید |
| بازر اصلاً صدا نمی‌دهد | قطبیت اشتباه یا بازر برعکس وصل شده | تنظیم `BUZZER_ACTIVE_LOW` و جهت +/− بازر را بررسی کنید |
| یک LED هیچ‌وقت روشن نمی‌شود | LED برعکس وصل شده | پایه‌هایش را جابه‌جا کنید: پایهٔ بلند به سمت مقاومت |
| کارت فقط از ۰ تا ۱ سانتی‌متر خوانده می‌شود یا اصلاً خوانده نمی‌شود | فلز در نزدیکی، سیم‌های بلند SPI، یا تغذیهٔ ضعیف | آنتن را از فلز دور کنید؛ سیم‌ها را کوتاه کنید؛ آداپتور USB دیگری امتحان کنید |
| بعضی کارت‌ها هیچ‌وقت خوانده نمی‌شوند | کارت ۱۳٫۵۶ مگاهرتز ISO 14443A نیست (مثلاً کارت ۱۲۵ کیلوهرتز) | از کارت ۱۳٫۵۶ مگاهرتز استفاده کنید |
| چشمک کوتاه قرمز هر ۳ ثانیه | حالت سرور: سرور در دسترس نیست | آدرس سرور، کلید دستگاه و شبکه را بررسی کنید |

## ۱۱. اطلاعات مرجع

### پایه‌های استفاده‌شدهٔ Wemos D1 mini

| برچسب | GPIO | کاربرد | شرط زمان بوت |
